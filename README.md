# moonjang — Korean Grammar Practice

Локальное приложение для упражнений по корейской грамматике. Основные файлы: `index.html`, `css/styles.css`, `js/app.js`, `js/storage.js`, `js/generator.js`.

## Запуск

Откройте `index.html` в современном браузере. Библиотека, задания и прогресс хранятся в `localStorage` этого браузера и на этом компьютере. Экспортируйте JSON-резервную копию перед очисткой данных браузера или переносом на другое устройство. Для корейского веб-шрифта при первом открытии требуется интернет; системные шрифты остаются резервным вариантом.

## Создание тем и генерация

Ввод названия отправляет запрос `POST /api/generate` с JSON `{ "grammar": "...", "exerciseCountPerDirection": 30, "sourceLanguage": "kk", "targetLanguage": "ko" }`. В этой поставке API не подключён, поэтому приложение честно показывает сообщение, а не создаёт примерные ответы. Чтобы активировать генерацию, разместите приложение за вашим сервером и реализуйте same-origin endpoint `/api/generate`. Сервер должен анализировать смысл, форму, ограничения и контексты конструкции и возвращать:

```json
{
  "analysis": { "meaning": "...", "formation": "...", "usage": "...", "restrictions": "...", "similarForms": "..." },
  "exercises": [
    { "direction": "kk-ko", "number": 1, "prompt": "Қазақша сөйлем.", "answer": "한국어 문장.", "explanation": "Қажет болса" },
    { "direction": "ko-kk", "number": 1, "prompt": "한국어 문장.", "answer": "Қазақша сөйлем.", "explanation": "Қажет болса" }
  ]
}
```

Массив должен содержать ровно 30 записей `kk-ko` и 30 `ko-kk`; каждое задание обязано иметь исходное предложение и качественный перевод. Настройте сервер на вызов выбранной языковой модели и проверяйте ответ по этой схеме и правилам до отправки браузеру. Секретный API-ключ храните только в переменных окружения сервера, никогда в HTML или JavaScript. Нельзя безопасно вызывать платную модель напрямую из локальной страницы: браузеру нечем скрыть ключ. Ошибка/отсутствующий endpoint не перезаписывает библиотеку.

После подключения вводите название грамматики и нажимайте «Создать упражнения». Новая тема добавляется к существующим. Повторное создание той же темы обновляет её; если нужно сохранить отдельную редакцию, используйте отличающееся название.

## Учебные функции

- Два направления по 30 предложений, отдельные вкладки с ответами.
- Ответы по одному открываются после подтверждения; весь текущий блок раскрывается отдельным подтверждением.
- Отметки переключаются между «Не выполнено», «Выполнено» и «Проверено»; прогресс можно сбросить.
- Печать выводит упражнения без ответов и интерфейсных элементов.
- Импорт объединяет темы по ID и не удаляет другие темы; экспорт сохраняет библиотеку и прогресс в JSON.
- Переключатель светлой и тёмной темы, поиск и адаптивная вёрстка.

Для файлового импорта приложение ожидает JSON-резервную копию этого формата. `localStorage` отделён по происхождению страницы: если браузер считает локальный файл и локальный сервер разными источниками, перенесите данные через экспорт/импорт.

## Запуск генератора (Windows)

Двойной щелчок по `index.html` открывает только статическую страницу, без `/api/generate`; поэтому кнопка не могла создавать новую тему. Теперь в проект добавлен локальный сервер без дополнительных npm-зависимостей.

1. Установите Node.js, если команда `node --version` ещё не работает.
2. Откройте PowerShell в папке `outputs`.
3. Чтобы ключ не попадал в код или команду, запросите его в скрытом поле ввода PowerShell, затем запустите сервер:

   ```powershell
   $credential = Get-Credential -UserName "OpenAI API key" -Message "Вставьте API-ключ в поле пароля"
   $env:OPENAI_API_KEY = $credential.GetNetworkCredential().Password
   node server.mjs
   ```

4. Откройте `http://127.0.0.1:4173` вместо `index.html` напрямую. Для остановки сервера нажмите Ctrl+C; ключ останется только в окружении этого окна PowerShell.

Сервер хранит API-ключ только в переменной окружения и вызывает [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses) со структурированным JSON-ответом. Модель по умолчанию — `gpt-4.1-mini`; её можно изменить переменной окружения `OPENAI_MODEL`. Использование API тарифицируется OpenAI по настройкам вашего аккаунта. Если ключ не задан, страница покажет точное сообщение о настройке; генератор не подменяет модель случайными или заранее заготовленными заданиями.
